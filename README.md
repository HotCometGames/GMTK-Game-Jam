# GMTK Game Jam
One Last Jump

3… 2… 1… make it count-

One Last Jump is a puzzle-platformer where walking is free, but every special action ticks your move counter closer to zero. Guide your robot using jumps, dashes, crate pushes, and grapples. Each level is a countdown: spend your limited actions wisely, because trying to make one more move at zero means round over.

Break through glass, dodge spikes, manipulate crates, find the real door, and reach the exit before your options run out. All assets, artwork, and animations were hand drawn.

Controls Move: A/D or Left/Right Arrow
